Unit 15 · REST APIs with JAX-RS

The original course never covered this, yet it’s how most Jakarta EE backends talk to the world today. JAX-RS (Jakarta RESTful Web Services) turns Java methods into HTTP endpoints that usually speak JSON.

↩︎
Recap HTTP = request/response; a client sends GET /accounts/123, the server answers with data and a status code (Unit 00). JAX-RS maps those requests to your methods.
concept

REST in one paragraph

Model your system as resources (things: an account, an order) each at a URL, and act on them with HTTP verbs:

VerbMeansExample
GETreadGET /accounts/123
POSTcreatePOST /accounts
PUTreplace/updatePUT /accounts/123
DELETEremoveDELETE /accounts/123

Common status codes: 200 OK, 201 Created, 204 No Content, 400 Bad Request, 404 Not Found, 500 Server Error.

concept

A resource class

import jakarta.ws.rs.*;
import jakarta.ws.rs.core.MediaType;
import jakarta.ws.rs.core.Response;
import jakarta.inject.Inject;

@Path("/accounts")                                   // base path
@Produces(MediaType.APPLICATION_JSON)                // methods return JSON
@Consumes(MediaType.APPLICATION_JSON)                // methods accept JSON
public class AccountResource {

    @Inject AccountService accounts;                 // your EJB / CDI bean (Unit 13/14)

    @GET
    public List<Account> list() {
        return accounts.findAll();
    }

    @GET @Path("/{id}")
    public Response getOne(@PathParam("id") Long id) {
        Account a = accounts.get(id);
        return (a != null)
            ? Response.ok(a).build()
            : Response.status(Response.Status.NOT_FOUND).build();
    }

    @POST
    public Response create(Account incoming) {       // JSON body -> Account, automatically
        Account saved = accounts.open(incoming.getHolder());
        return Response.status(Response.Status.CREATED).entity(saved).build();
    }

    @DELETE @Path("/{id}")
    public void delete(@PathParam("id") Long id) {
        accounts.remove(id);
    }
}
AnnotationJob
@PathURL this class / method answers on
@GET @POST @PUT @DELETEWhich HTTP verb triggers the method
@PathParamPull a value out of the URL (/{id})
@QueryParamPull a value from ?name=…
@Produces / @ConsumesResponse / request body format (usually JSON)

JSON ↔ Java conversion is automatic via JSON-B — a public field or getter becomes a JSON property, and an incoming JSON body is bound to your method parameter.

Where JAX-RS sits
      A JAX-RS resource is a thin edge. It parses the request, calls your session bean / CDI service
      for the real work (transactions, security, persistence all still apply there), and shapes the
      response. Keep business logic out of the resource class.

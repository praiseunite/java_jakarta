Part 1 · Connecting the Presentation Tier to Enterprise Beans

In a standard Jakarta EE architecture, the web tier acts as a Local Client to your business beans, while remote administrative tools or external microservices act as Remote Clients:

Client TypeComponentHow It Accesses EJBCommunication Boundary
Web Tier (Local) JSF Facelets + CDI Backing Bean Injected via @EJB or @Inject into backing bean Same JVM (in-memory, nanoseconds, pass-by-reference)
Distributed (Remote) Standalone Java Desktop / External Server Looked up via InitialContext.lookup("ejb:...") Network Boundary (serialized over HTTP-Remoting / RMI, milliseconds)

Part 2 · The Integrated Currency Converter Lab

Let's examine how a Facelet page invokes an enterprise bean that provides both a @Local view for the web interface and a @Remote view for external partner bank integrations.

1. The Dual Business Interfaces
// Local view for the JSF Web Tier
@Local
public interface CurrencyLocal {
    double convert(double amount, String from, String to);
}

// Remote view for Partner Banks & Desktop Terminals
@Remote
public interface CurrencyRemote {
    double convert(double amount, String from, String to);
}
2. CurrencyConverterBean.java — Stateless Bean implementing both views
package com.globalbank.ejb;

import jakarta.ejb.Stateless;

@Stateless
public class CurrencyConverterBean implements CurrencyLocal, CurrencyRemote {

    @Override
    public double convert(double amount, String from, String to) {
        // Simplified exchange rate calculation
        if ("USD".equalsIgnoreCase(from) && "EUR".equalsIgnoreCase(to)) return amount * 0.92;
        if ("EUR".equalsIgnoreCase(from) && "USD".equalsIgnoreCase(to)) return amount * 1.09;
        return amount; // default 1:1
    }
}
3. ConverterBackingBean.java — CDI Backing Bean for JSF
package com.globalbank.web;

import jakarta.ejb.EJB;
import jakarta.enterprise.context.RequestScoped;
import jakarta.inject.Named;
import com.globalbank.ejb.CurrencyLocal;

@Named("currencyBean")
@RequestScoped
public class ConverterBackingBean {

    @EJB
    private CurrencyLocal currencyService; // Injected as a local client

    private double amount = 100.0;
    private String from = "USD";
    private String to = "EUR";
    private double result;

    public void calculate() {
        this.result = currencyService.convert(amount, from, to);
    }

    // Getters and setters for amount, from, to, result...
}
4. converter.xhtml — Facelets Form
<!DOCTYPE html>
<html xmlns="http://www.w3.org/1999/xhtml"
      xmlns:h="jakarta.faces.html">
<h:head><title>Currency Exchange</title></h:head>
<h:body>
    <h:form>
        <h:outputLabel value="Amount: "/>
        <h:inputText value="#{currencyBean.amount}"/>

        <h:commandButton value="Convert" action="#{currencyBean.calculate}"/>
    </h:form>

    <h:panelGroup rendered="#{currencyBean.result gt 0}">
        <p>Converted Value: <strong>#{currencyBean.result}</strong></p>
    </h:panelGroup>
</h:body>
</html>

Part 3 · Top 3 Integration Gotchas for Sessions 5 & 6

1️⃣
Trap 1: java.io.NotSerializableException on Remote Calls

Symptom: Remote client call fails with WriteObjectException: NotSerializableException: com.model.Customer.

Fix: When passing custom objects to @Remote methods, every object and every nested member field must implement java.io.Serializable.

2️⃣
Trap 2: Submitting a form without action method firing

Symptom: Clicking the submit button reloads the page, but the backing bean action method is never executed.

Fix: Check Phase 3 (Process Validation). If an input fails validation or conversion, JSF skips directly to Phase 6. Add an <h:messages /> tag to your view to display the hidden validation error!

3️⃣
Trap 3: Annotating one interface with both @Local and @Remote

Symptom: WildFly deployment fails with an EJB specification violation exception.

Fix: A single Java interface cannot be both local and remote. Declare two separate interfaces (e.g., OrderServiceLocal and OrderServiceRemote) and let the bean implement both.

Local vs RemoteLocal = in-memory pointer (nanoseconds); Remote = serialized network call (milliseconds).
